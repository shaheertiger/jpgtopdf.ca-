Watermark PDF

Quick answer

Open the PDF, type the text (CONFIDENTIAL is filled in), choose diagonal, horizontal or tiled, an opacity of 12%, 25% or 45%, and a colour, then press Add watermark. It is drawn as real text over the page, so it prints sharply. It can be removed by someone with a PDF editor; flatten the pages to make that harder.

How to watermark a PDF

  1. Open the PDF. Select it or drop it in the box.
  2. Type the watermark. For example DRAFT, COPY, SAMPLE, or "For Jane Doe only".
  3. Pick layout, size, opacity and colour. "Fit the page" sizes the text to the page automatically.
  4. Choose the pages. Leave the range as it is for every page, or type pages such as 2-5.
  5. Download. Press "Add watermark". Open the file and check the text doesn't hide anything important; this is the step people skip. If it does, choose Light.

How do I make a watermark hard to remove?

A text watermark sits on its own over the page content, so a PDF editor can delete it. To make it part of the page, run the watermarked file through Flatten PDF with "Everything": each page becomes an image with the watermark baked in. Text is then no longer selectable, so keep your original.

Common uses

Sending ID documents

When a landlord or employer asks for a copy of your ID, a tiled watermark such as "For rental application at 12 Main St only" makes the copy harder to reuse elsewhere.

Drafts and reviews

DRAFT on every page stops an unfinished contract being mistaken for the final one.

Samples and previews

SAMPLE on a portfolio or template preview, at light opacity so the work still shows.

Frequently asked questions

Is my PDF uploaded?

No. The watermark is added in your browser and the file stays on your device.

Can I use an image or logo as a watermark?

Not here. To place a logo, use Add image to PDF.

Can I watermark only some pages?

Yes. Type pages in the Pages box, for example 1, 3-5.

Can I use Arabic, Hindi or Chinese text?

No. The built-in font covers Western European alphabets only, and unsupported letters show as "?".

Does it work on rotated pages?

Yes. The watermark is placed relative to the page as it is displayed.

Is it free?

Yes, with no account and no extra branding of ours.
