OCR PDF — Make a Scanned PDF Searchable

Drop a scanned PDF, pick the language, and download a copy you can search and copy from.

OCR PDF

Quick answer

Drop a scanned PDF, choose its language and press Make searchable. Each page is read at about 300 DPI and an invisible text layer is laid over it, so you can search, select and copy, while the page looks exactly as before. Expect roughly 3–10 seconds per page on a laptop, longer on a phone. Printed text works well; handwriting does not.

How to OCR a PDF

  1. Drop the scanned PDF. The page count appears; long files take a while, so check it first.
  2. Pick the document's language. This is the setting that matters most. Accented letters (é, ç, ñ, ã, ü) come out wrong if the language is wrong. For a bilingual form, choose English + French or English + Spanish.
  3. Leave "Skip pages that already have text" ticked. Pages that already contain text are left alone, which saves time on mixed files.
  4. Press Make searchable (OCR) and keep the tab open. The status line shows the page it is on and an estimate of the time left.
  5. Download the searchable PDF. The recognised text also appears below, so you can copy it straight away.

How do I make a scanned PDF searchable?

Run it through this tool. A scan is a stack of pictures, so a PDF reader has no words to search. OCR (optical character recognition) reads the letters in each picture and stores them as invisible text in the right place on the page. After that, Ctrl+F or Cmd+F finds words, and you can highlight and copy lines.

Does OCR change how my PDF looks?

No. The original page is kept as it was and the text layer is invisible. The file gets a little bigger, because the text is added, but the page images are not re-compressed. To make the result smaller, run it through Compress PDF afterwards; the text layer stays.

How accurate is OCR?

It depends mostly on the scan. Clean, straight, printed pages scanned at 200–300 DPI usually come out very well. Accuracy drops with blurry phone photos, skewed pages, faint print, small fonts, stamps over text, and tables with lines through the words. Always check names, numbers and amounts before relying on them. Handwriting is not recognised.

Frequently asked questions

Is OCR PDF free?

Yes. It is free, with no sign-up, no page cap and no watermark.

Is my scanned PDF uploaded?

No. Recognition runs in your browser. The first time, the page downloads the recognition engine and language data from our own server; your file stays on your device.

Which languages does it support?

English, French, Spanish, Portuguese and German, plus combined English + French and English + Spanish for bilingual documents.

Can it read handwriting?

No. It is built for printed text. Handwritten notes and signatures are not recognised.

Will my PDF look different afterwards?

No. The pages are kept exactly as they were; the text layer is invisible.

Does it work offline?

Usually, once the page and the recognition data have loaded and the tab stays open. The first run needs a connection to fetch the data.

Why does my searchable PDF not find a word?

The word was probably misread. Check the recognised text shown below the tool; a sharper scan usually fixes it.
