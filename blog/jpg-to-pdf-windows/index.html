How to Convert JPG to PDF on Windows 10 and 11

By the JPGtoPDF.ca team · Updated 2026-11-11 · 5 min read · Lire en français

You have JPG files on a Windows PC and need them as one PDF for an application, an invoice or a school portal.

Windows 10 and 11 do it built in: select the JPGs in File Explorer, right-click → Print, choose Microsoft Print to PDF, untick Fit picture to frame, and click Print. Windows asks where to save the PDF. If you want to control page order and margins, use our free converter in Edge or Chrome.

The built-in way is hidden because Windows treats "make a PDF" as printing to a virtual printer. One checkbox in that dialog also crops your photos without warning. This guide covers both methods, that checkbox, and how to keep quality and size under control.

How Does Microsoft Print to PDF Work?

Microsoft Print to PDF is a virtual printer installed with Windows 10 and 11. Anything you can print, you can "print" to a PDF file instead of paper. No download, no account.

What Most People Don't Know

The Print Pictures dialog has a Fit picture to frame box that's ticked by default. It fills the whole page by cropping the edges of your photo. For a document photo, that can cut off the top line or a signature.

Key point: Always untick Fit picture to frame when converting documents. Your photo will be scaled to fit inside the page instead of cropped.

Method 1: File Explorer → Print to PDF (Several JPGs at Once)

Step 1: Select the JPGs

Open the folder in File Explorer. Click the first image, hold Ctrl and click the others (or Ctrl+A for all).

Step 2: Right-Click → Print

Right-click a selected file. On Windows 11, choose Show more options first, then Print. The Print Pictures window opens.

Step 3: Choose the Printer and Layout

  • Printer: Microsoft Print to PDF
  • Paper size: Letter (Canada/US) or A4
  • Layout (right side): Full page photo, one image per page

Step 4: Untick "Fit Picture to Frame"

This is the step people get wrong. Untick it so nothing is cropped.

Pro tip: Windows orders the pages by how the files are sorted in the folder. Rename them 01, 02, 03… before printing if order matters.

Step 5: Print and Name the File

Click Print. A Save Print Output As window appears: choose a folder, type a name and click Save.

Method 2: Photos App → Print (One Photo)

  1. Open the JPG in Photos.
  2. Press Ctrl+P (or ⋯ → Print).
  3. Set Printer to Microsoft Print to PDF, choose orientation and page size.
  4. Click Print and save the file.

Method 3: Browser Converter (Most Control)

  1. Open jpgtopdf.ca in Edge, Chrome or Firefox.
  2. Drag the JPGs onto the box, or click Select images.
  3. Drag thumbnails to reorder, remove any you don't need.
  4. Pick page size, orientation and margin, then Download PDF.

Files are converted in the browser on your PC; nothing is uploaded. JPGs are placed in the PDF without re-compression, see JPG to PDF without losing quality.

Desktop Converter Software (Use With Caution)

Searching "JPG to PDF Windows" brings up free downloads that bundle toolbars, change your default browser, or add watermarks until you pay.

The Real Risks

  • Bundled extra software in the installer.
  • Trial versions that watermark every page.
  • Background updaters running at startup.

Safety checklist: download only from the developer's own site, read each installer screen, decline extras.

Bottom line: Windows has Print to PDF built in. You don't need to install anything to convert JPGs.

Frequently Asked Questions

How do I convert JPG to PDF on Windows 10 for free?

Select the JPGs, right-click → Print, choose Microsoft Print to PDF, untick Fit picture to frame and click Print. It's built in.

How do I convert JPG to PDF on Windows 11?

Same steps, but right-click → Show more options → Print. Or open the photo in Photos and press Ctrl+P.

How do I combine multiple JPGs into one PDF on Windows?

Select them all in File Explorer and print them together to Microsoft Print to PDF. They come out as one PDF, one image per page.

Why is my photo cropped in the PDF?

Fit picture to frame was ticked. Untick it in the Print Pictures dialog.

Does Print to PDF reduce quality?

It re-renders the image for a page, which can soften fine text. A browser converter that keeps the original JPG avoids that.

Can I convert JPG to PDF offline on Windows?

Yes. Microsoft Print to PDF works without internet. Our converter also keeps working once the page has loaded.

The Bottom Line
