PDF to text

Quick answer

Drop a PDF and press Extract text. The tool reads the text already stored in the PDF, rebuilds it line by line, and shows it in a box you can copy, plus a UTF-8 .txt download. It takes seconds and does not guess at letters. If the PDF is a scan (pictures of pages), there is no text to read: use OCR PDF first.

How to convert a PDF to text

  1. Drop your PDF. The page count appears next to the file name.
  2. Choose whether to mark pages. "Mark where each page starts" adds a line like --- Page 3 ---. Keep it on if you need to find things later; turn it off for clean text to paste elsewhere.
  3. Press Extract text. The text appears in the box and the .txt file downloads.
  4. Check the result line. It says how many pages had text. Pages with none are scans; this is the step people skip. Run those through OCR PDF first.

How do I copy text from a PDF that won't let me select it?

If you can't select text in a reader but the PDF is not a scan, the text is usually still there. Drop it here and press Extract text, then Copy text. If the tool reports no text, the pages are images, and you need OCR PDF to recognise the words.

Why does the text come out in the wrong order?

A PDF stores text as positioned pieces, not paragraphs. The tool joins pieces that sit on the same line and starts a new line when the position moves down. Two-column articles, sidebars and tables can come out with lines from different columns mixed together. The words are all there; the layout isn't.

Can I edit the extracted text in Word or Google Docs?

Yes. Open the .txt file in Word, Google Docs, Pages or any text editor, or paste from Copy text. You get the words without the original formatting, so headings, bold and tables need to be redone. Line breaks follow the lines of the PDF, which means a paragraph may be split over several short lines; most editors can join them with find-and-replace. If you need the page to look the same, keep the PDF and copy only the parts you need.

Frequently asked questions

Is PDF to text free?

Yes. It is free, with no sign-up and no limit on how often you use it.

Is my PDF uploaded?

No. The text is read in your browser and the .txt file is made on your device.

Does it work on scanned PDFs?

No. A scan has no text layer. The tool tells you so and links to OCR PDF, which recognises the words.

Does it keep formatting?

No. You get plain text: no bold, fonts, tables or images, just the words in line order.

What encoding is the .txt file?

UTF-8, so accented letters and most scripts are kept as in the PDF.

Can I extract text from one page only?

The tool reads every page. Use Extract PDF pages first to make a PDF of just the pages you want.

Is the extracted text accurate?

It is exactly the text stored in the PDF, with no guessing. Accuracy only becomes a question with OCR on scans.
