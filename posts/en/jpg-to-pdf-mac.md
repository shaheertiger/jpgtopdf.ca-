You have a JPG on your Mac and the form wants a PDF. You might need one image converted, or twenty merged into one file.

**The fastest built-in way is Finder:** select the JPGs, Control-click → **Quick Actions** → **Create PDF**. A PDF appears next to them in a second. For one image with page-size options, open it in **Preview** → **File** → **Export as PDF**.

Apple spreads this across three places (Finder, Preview and the Print dialog), and each behaves a little differently. This guide shows all three, the order trap in Finder, and when a browser converter is the better choice.

## Why Are There Three Ways on a Mac?

macOS treats PDF as a first-class format. Preview can save any image as PDF, Finder has a Create PDF quick action, and every app's Print dialog has a **PDF** menu. They all work offline and are free.

### What Most People Don't Know

Finder's Create PDF orders pages by **file name**, not by the order you clicked them. IMG_0102 comes before IMG_0099 only if the names sort that way. Rename files 01, 02, 03 first, or use Preview's sidebar to drag pages into place.

> **Key point:** For multi-page PDFs where order matters, use Preview (drag pages in the sidebar) or a converter where you drag thumbnails.

## Method 1: Finder Quick Action "Create PDF"

### Step 1: Select the Images

In Finder, click the first JPG and Command-click the rest.

### Step 2: Control-Click → Quick Actions → Create PDF

The new PDF appears in the same folder, named after the first image. Available since macOS Mojave.

### Step 3: Rename It

Click the file name once, pause, click again, and type a clear name.

> **Pro tip:** If Create PDF isn't listed, open System Settings → Privacy & Security → Extensions → Finder (or Quick Actions on older macOS) and make sure it's ticked.

## Method 2: Preview → Export as PDF

### For One Image

1. Double-click the JPG to open it in Preview.
2. **File** → **Export as PDF**.
3. Choose a name and folder, click **Save**.

### For Several Images in One PDF

1. Select all the JPGs in Finder and open them together (they open in one Preview window).
2. Show the sidebar: **View** → **Thumbnails**.
3. Drag thumbnails to reorder. Select all with **Command-A**.
4. **File** → **Print**, open the **PDF** menu at bottom left, choose **Save as PDF**.

Set **Paper Size** to US Letter in the print dialog if the PDF will be printed in Canada or the US.

## Troubleshooting on Mac

| Problem | Fix | Why it works |
|---|---|---|
| No Create PDF in Quick Actions | Turn it on in Extensions settings | It can be disabled |
| Pages in the wrong order | Rename 01, 02… or reorder in Preview's sidebar | Finder sorts by name |
| Export as PDF makes one page only | Use File → Print → Save as PDF for several | Export saves the current image |
| PDF is huge | Resize in Preview (Tools → Adjust Size) first | PDF size follows the images |
| HEIC photos from iPhone | Preview and Finder accept them; for websites, export as JPEG first | Some sites reject HEIC |

Menu labels change between macOS versions, so look for the nearest match.

## Adding a Picture to an Existing PDF

To insert an image into a PDF you already have, open the PDF in Preview, show thumbnails, then drag the JPG into the sidebar where you want the new page. Save. For merging two PDFs, the same drag works with a second PDF.

## Paid PDF Editors (Use With Caution)

Many Mac App Store and web PDF editors charge a subscription for something Preview does free.

### The Real Risks

- Subscriptions for a one-off job.
- Some web editors upload files to their servers.
- Trial watermarks on exported pages.

> **Bottom line:** Finder and Preview cover JPG to PDF completely. Pay only if you need OCR or form editing.

## Frequently Asked Questions

### How do I convert a JPG to PDF on a Mac?

Open it in Preview and choose File → Export as PDF. Or select it in Finder, Control-click and choose Quick Actions → Create PDF.

### How do I combine multiple JPGs into one PDF on a Mac?

Select them in Finder → Quick Actions → Create PDF. For a custom order, open them together in Preview, reorder in the sidebar, then Print → Save as PDF.

### Does Preview reduce image quality?

Export as PDF keeps the image largely intact. Our converter places the original JPG in the PDF without re-compressing it.

### Can I convert PNG to PDF on a Mac the same way?

Yes. Finder, Preview and our converter all accept PNG. See [PNG to PDF](/blog/png-to-pdf/).

### Why don't I see Create PDF?

Quick Actions needs macOS Mojave or later and the action must be enabled under Extensions.
