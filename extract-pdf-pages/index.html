Extract PDF Pages — Save Selected Pages as a New PDF

Add a PDF, choose the pages you want, and download them as a new file.

Extract PDF pages

Quick answer

To extract pages from a PDF, add the file, then tick the pages you want or type them, for example "1, 3-5". Press Extract pages to get one new PDF with just those pages. Tick Save each page as a separate PDF to get one file per page in a ZIP instead. Pages are copied as they are, and the file stays on your device.

How to extract pages from a PDF

  1. Add the PDF. Tap Select a PDF or drop it on the box.
  2. Choose the pages. Tick thumbnails, or type numbers and ranges in Pages to extract.
  3. Decide the order. Ticked pages come out in document order. Typed pages come out in the order you type them, so "5, 1, 2" puts page 5 first. This is the detail most people miss.
  4. Pick one file or many. Leave the box unticked for one PDF; tick Save each page as a separate PDF for a ZIP of single pages.
  5. Press Extract pages and download.

How do I save one page of a PDF as its own file?

Tick that page (or type its number) and press Extract pages. You get a one-page PDF named like "report-extract.pdf". The original file is not changed.

How do I pull pages out in a different order?

Type them in the order you want, for example "7, 2, 3". The new PDF follows the typed order. For drag-and-drop reordering of a whole document, use Organize PDF.

Frequently asked questions

Is my file uploaded?

No. The pages are extracted by your browser on your own device and nothing is sent to a server.

Does extracting change the quality of the pages?

No. Pages are copied without re-rendering, so text and images stay exactly as sharp.

What is the difference between extract and split?

Extract saves the pages you choose and leaves the rest out. Split PDF cuts the whole file into several parts.

Can I extract pages on a phone?

Yes, in Safari and Chrome on phones. Tap thumbnails to tick them.

Can I extract the same page twice?

No. Repeated page numbers are counted once, so each page appears a single time in the new file.

Does it work with password-protected PDFs?

No. Save or print an unlocked copy first, then extract from that copy.
