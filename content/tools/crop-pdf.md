## Quick answer

Open the PDF, drag a box over the area to keep on the page preview, or type the margins to cut in millimetres, choose the pages, and press Crop PDF. Nothing is re-rendered, so text stays sharp. Cropping hides what is outside the box in every reader, but the hidden content is still inside the file.

## How to crop a PDF

1. **Open the PDF.** Page 1 appears as a preview.
2. **Drag over the area to keep.** The margin boxes fill in as you drag; adjust them by typing if you need exact millimetres.
3. **Choose the pages.** Leave the range for all pages, or type a range. The same margins apply to every chosen page, so check that pages share a layout.
4. **Crop.** Press "Crop PDF". The file saves as yourfile-cropped.pdf.

## Does cropping delete the content outside the box?

No. Cropping sets the visible area of each page (the PDF crop box). Every reader hides what's outside it, and printing uses the cropped size, but the content is still in the file and someone with a PDF editor can bring it back. If you are removing private details, run the cropped file through [Flatten PDF](/flatten-pdf/) with "Everything", which turns each page into an image of only what is visible.

## Frequently asked questions

### Will cropping reduce quality?

No. Pages aren't re-rendered; only the visible area changes.

### Will it make the file smaller?

Usually not, because the hidden content stays in the file. [Compress PDF](/compress-pdf/) reduces size.

### Can I crop each page differently?

In one run every chosen page gets the same margins. Use page ranges and several runs for different layouts.

### Is my PDF uploaded?

No. Everything runs in your browser.

### Does it work on a phone?

Yes. Drag with your finger on the preview, or type the margins.

### Is it free?

Yes, with no account and no watermark.
