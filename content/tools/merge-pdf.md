## Quick answer

To merge PDFs, add two or more files, check the order in the list, and press **Merge PDF**. The pages are copied into one new file exactly as they are, with no re-rendering, so text stays sharp and quality does not drop. Everything happens in your browser: the files are never uploaded, and there is no account or watermark.

## How to merge PDF files

1. **Add your PDFs.** Tap **Select PDF files** or drop them on the box. You can add more later; new files go to the end of the list.
2. **Check the order.** This is the step people skip. The list order is the page order of the final file. Use ↑ and ↓ to move a file, or tick **Sort by file name**.
3. **Remove extras.** Tap ✕ next to any file you added by mistake.
4. **Press Merge PDF.** Each file is copied in turn; the status line shows progress.
5. **Download.** The merged file saves as merged.pdf. If your browser blocks the automatic download, use the **Download** button that appears.

## How do I merge PDFs in a specific order?

The list decides the order: file 1 comes first, then file 2, and so on. Move files with the ↑ and ↓ buttons until the list reads the way the final document should.

If your files are numbered, tick **Sort by file name**. The sort understands numbers, so "page-2.pdf" comes before "page-10.pdf", which a plain alphabetical sort gets wrong. You can still move files by hand after sorting.

Need to reorder single pages rather than whole files? Merge first, then open the result in [Organize PDF](/organize-pdf/) to drag pages around, rotate them or delete them.

## Does merging reduce quality?

No. Merging copies each page object into the new file. Nothing is printed, rasterized or re-compressed, so text stays selectable, images keep their resolution and vector drawings stay sharp. The merged file is usually close to the total size of the inputs; it can be a little smaller because the PDF is saved with compact object streams.

If the merged file is too big for an upload form, run it through [Compress PDF](/compress-pdf/) afterwards, or cut it into parts with [Split PDF by size](/split-pdf-by-size/).

## Can I merge PDFs on my phone?

Yes. The tool works in Safari on iPhone and in Chrome on Android. Tap **Select PDF files**, pick the files from Files, Drive or your Downloads, then merge. Very large files may run out of memory on older phones; if that happens, merge in two smaller batches and then merge the two results.

## Where people send merged PDFs

### Job application portals

Many applicant systems accept only one upload. Merge your cover letter, CV and references into a single PDF, cover letter first, so the reader sees them in the right order.

### IRCC and visa applications

Immigration portals often want each document type as a single file. Merge the pages of one document (for example all pages of a bank statement) into one PDF. IRCC limits each file to about 4 MB or 5 MB depending on the account, so compress afterwards if needed. Our [IRCC documents guide](/blog/ircc-documents-pdf/) covers the details.

### Gmail (25 MB) and Outlook (20 MB)

One attachment is easier to open than ten. Merge the files, check the size in the result card, and compress if it is over the email limit.

### Court e-filing and tax portals

E-filing systems usually want one PDF per submission, with exhibits in order. Merge them in the order of your index, then add numbers with [Add page numbers](/add-page-numbers/) if the court requires them.

### School assignment uploads

Course sites often take one file. Merge the assignment, the appendix and scanned handwritten pages into one PDF before you submit.

## Troubleshooting

| Problem | Fix | Why |
|---|---|---|
| "This PDF is password-protected" | Open it in a PDF reader, remove the password or print to a new PDF, then add it again | The tool cannot read encrypted files |
| "Does not look like a valid PDF" | Re-save the file from the app that made it | The file is damaged or is not really a PDF |
| Pages in the wrong order | Fix the list order before merging, or reorder pages in Organize PDF | The merge follows the list exactly |
| Merged file is too big to upload | Compress it, or split it by size | Merging adds sizes together |

| Browser tab crashes | Merge in smaller batches | Very large files can exceed a phone's memory |

## Frequently asked questions

### Is it safe to merge private documents here?

Yes. The files are read and combined by your own browser and never leave your device. Nothing is uploaded or stored, so contracts, IDs and bank statements stay private.

### How many PDFs can I merge at once?

There is no set number. The practical limit is your device's memory, so a laptop can handle far more than an older phone. For very large jobs, merge in batches.

### Will the merged PDF keep my bookmarks and links?

Page content, including links drawn on the page, is copied as it is. The document outline (bookmarks) of the original files is not rebuilt in the merged file, so you may need to add bookmarks again in a PDF editor.

### Do fillable forms still work after merging?

They may not. The pages and their visible content are copied, but interactive form fields may not carry over reliably. Fill in the form and flatten it before merging if the values matter.

### Can I merge a password-protected PDF?

Not directly. Remove the password first by opening the file in a PDF reader and saving or printing an unlocked copy, then add that copy.

### Can I merge images and PDFs together?

Not in this tool; it accepts PDFs only. Turn the images into a PDF with [JPG to PDF](/) first, then merge that file with the others.

### Does it add a watermark or change my pages?

No. There is no watermark, and the pages are copied without being re-rendered, so they look exactly as they did in the original files.
