Alternate and Mix PDF — Interleave Pages From Two PDFs

Add the front-side PDF, then the back-side PDF, tick reverse if needed, and download one mixed file.

Alternate and mix PDF

Quick answer

Add two PDFs and the tool takes one page from each in turn: A1, B1, A2, B2, and so on. Tick Reverse order on a file whose pages came out last-page-first, which is what a one-sided scanner does to the back sides. If one file is longer, its extra pages go at the end. Pages are copied as they are, so quality does not change.

How to alternate and mix PDF pages

  1. Add the first PDF. This is file A, usually the front sides (pages 1, 3, 5…).
  2. Add the second PDF. This is file B, usually the back sides (pages 2, 4, 6…). You can add more files; each gets the next letter.
  3. Tick Reverse order on the back sides if they were scanned flipped. This is the step people miss. When you turn a stack over and feed it again, the last back side is scanned first. The status line shows the resulting order, such as "A1, B3, A2, B2…", so you can check before saving.
  4. Press Mix PDFs. The file downloads as mixed.pdf, and a Download button stays on screen in case the browser blocked it.

How do I combine front and back scans into one PDF?

Scan the front sides as one PDF, flip the stack, and scan the back sides as a second PDF. Add the fronts first and the backs second. If the backs came out in reverse (page 6 first, page 2 last), tick Reverse order on the second file. The result reads 1, 2, 3, 4, 5, 6 in the right order.

If a page ends up upside down because the stack was turned the wrong way, fix it afterwards with Rotate PDF.

What happens if the two PDFs have a different number of pages?

The tool keeps alternating until the shorter file runs out, then adds the rest of the longer file at the end, in order. For a duplex scan this usually means a back side is missing or a blank back was skipped. Check the page counts shown next to each file before you mix.

Use cases

One-sided office scanner, two-sided document

Most office feeders and home all-in-ones only scan one side. Scan fronts, then backs, and mix them here instead of reordering 40 pages by hand.

Signed contract returned as two scans

A client scans the odd and even pages separately. Mix them back into one file before you file it or send it on.

Bilingual documents side by side

Put an English PDF and a French PDF of the same form page by page, so each English page is followed by its translation.

Slides and speaker notes

Exported slides in one PDF and notes pages in another can be interleaved so each slide sits next to its notes.

Frequently asked questions

Is the Alternate and Mix PDF tool free?

Yes. It is free with no account, no watermark and no daily limit.

Are my PDFs uploaded?

No. The pages are combined in your browser on your own device, and nothing is sent to a server.

Can I mix more than two PDFs?

Yes. Add three or more files and the tool takes one page from each in turn: A1, B1, C1, A2, B2, C2, and so on.

Does mixing reduce quality?

No. Pages are copied into the new file as they are, without re-rendering, so text and images stay exactly the same.

What does Reverse order do?

It reads that file from its last page to its first before mixing. Use it for back sides scanned after flipping the stack.

Can I change the order after mixing?

Yes. Open the mixed file in Organize PDF to drag individual pages into place.
